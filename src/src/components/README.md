# Components (UI agnostique)

Ce dossier contient les **composants réutilisables**, indépendants du métier.  
Ils servent de base au design system interne.

## Rôle
- Fournir des briques UI génériques.
- Être utilisables dans n’importe quelle page ou feature.

## Exemples
- `Button`
- `Input`
- `Table`
- `Card`
- `Modal`
- `Page` (layout simple)

## Ce qu’on ne met pas ici
- Pas de logique métier.
- Pas de composants liés à un domaine (territoires, shuttles…).
