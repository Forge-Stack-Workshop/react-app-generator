# src/

Application source root.

| File        | Role                                                           |
| ----------- | -------------------------------------------------------------- |
| `main.tsx`  | Entry point — mounts the React tree, starts MSW in development |
| `App.tsx`   | Router setup with lazy-loaded page routes                      |
| `App.css`   | App-level styles                                               |
| `index.css` | Global baseline styles                                         |

See sub-folder READMEs for details on each layer.
